# MORPH. 아바타 스튜디오

사진에서 색과 얼굴 영역을 읽어 움직이는 캐릭터로 바꾸는 브라우저 기반 아바타 제작 도구입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다.

## 포함된 기능

- 사진 드래그 앤 드롭 및 파일 선택
- FaceDetector 지원 브라우저에서 얼굴 영역 감지
- 얼굴 감지 미지원 환경에서 사진 영역 기반 색 추출
- 웹캠에서 33개 전신 포즈 랜드마크 실시간 추적
- 머리, 목, 어깨, 팔꿈치, 손목, 손, 골반, 무릎, 발목, 발을 독립 관절로 연결
- 손 모양과 발 방향, 몸 기울기와 점프를 아바타 동작에 연결
- 팔의 깊이와 몸통 교차를 감지해 앞뒤 레이어 자동 전환
- 로봇 친구가 제시하는 무작위 포즈 문제 10종
- 5초 제한 시간과 종료 순간 싱크로율 채점
- 종료 순간 웹캠 사진, 이름, 문제와 점수를 저장하는 로컬 순위표
- 피부색, 머리색, 상의색, 헤어 스타일 편집
- 온실, 노을, 한낮, 사이버 배경
- 로봇 친구의 왼쪽 및 오른쪽 배치
- 살랑, 인사, 춤, 점프, 팔짱 애니메이션
- 현재 장면 PNG 저장
- 모바일 레이아웃, 다크 모드, 모션 감소 설정 지원

웹캠은 브라우저 보안 정책상 `localhost` 또는 HTTPS 환경에서만 사용할 수 있습니다. 화면에 어깨부터 발목까지 보이도록 카메라에서 조금 떨어져 서면 안정적으로 추적됩니다.
